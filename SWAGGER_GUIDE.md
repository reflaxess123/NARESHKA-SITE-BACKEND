# Руководство по использованию Swagger UI

## Что такое Swagger UI?

Swagger UI - это интерактивная документация API, которая позволяет:

- Просматривать все доступные endpoints
- Тестировать API прямо в браузере
- Видеть структуру запросов и ответов
- Автоматически генерировать примеры

## Доступ к документации

Swagger UI доступен по адресу: **http://localhost:4000/api-docs/**

## Основные возможности

### 1. Просмотр документации

- Все endpoints сгруппированы по тегам (Theory Cards, Admin, User, General)
- Каждый endpoint содержит описание, параметры и примеры ответов
- Схемы данных описаны в разделе "Schemas"

### 2. Тестирование API

#### Шаг 1: Аутентификация

Большинство endpoints требуют аутентификации. Для тестирования:

1. Сначала залогиньтесь через фронтенд приложения или используйте endpoint `/auth/login`
2. После успешного логина cookie сессии автоматически сохранится в браузере
3. Swagger UI будет использовать эти cookies для аутентификации

#### Шаг 2: Выбор endpoint

1. Найдите нужный endpoint в списке
2. Нажмите на него для раскрытия деталей
3. Нажмите кнопку **"Try it out"**

#### Шаг 3: Заполнение параметров

1. **Query параметры**: заполните поля в разделе Parameters
2. **Path параметры**: введите значения для переменных в URL
3. **Request Body**: для POST/PATCH запросов заполните JSON в поле Request body

#### Шаг 4: Выполнение запроса

1. Нажмите кнопку **"Execute"**
2. Swagger покажет:
   - Curl команду
   - Request URL
   - Response body
   - Response headers
   - Response code

## Примеры использования

### 1. Получение списка теоретических карточек

**Endpoint**: `GET /api/theory/cards`

1. Откройте раздел "Theory Cards"
2. Найдите `GET /api/theory/cards`
3. Нажмите "Try it out"
4. Заполните параметры (опционально):
   - `page`: 1
   - `limit`: 10
   - `category`: "JS ТЕОРИЯ"
5. Нажмите "Execute"

### 2. Обновление прогресса по карточке

**Endpoint**: `PATCH /api/theory/cards/{cardId}/progress`

1. Найдите `PATCH /api/theory/cards/{cardId}/progress`
2. Нажмите "Try it out"
3. Введите `cardId` (например: "cmb4xxtcp0000kz57cvhy6dyn")
4. В Request body введите:
   ```json
   {
     "action": "increment"
   }
   ```
5. Нажмите "Execute"

### 3. Импорт Anki файла

**Endpoint**: `POST /api/admin/import-anki`

1. Найдите `POST /api/admin/import-anki` в разделе "Admin"
2. Нажмите "Try it out"
3. Нажмите "Choose file" и выберите .txt файл с Anki данными
4. Нажмите "Execute"

## Преимущества Swagger UI перед Postman

1. **Встроенная документация** - вся документация API находится прямо в коде
2. **Автоматическая синхронизация** - документация всегда актуальна
3. **Работа в браузере** - не требует установки дополнительного ПО
4. **Интерактивное тестирование** - можно сразу выполнять запросы
5. **Автоматические примеры** - Swagger генерирует примеры запросов и ответов

## Доступные группы API

### 1. Authentication (Аутентификация)

- `POST /auth/register` - Регистрация нового пользователя
- `POST /auth/login` - Вход пользователя
- `POST /auth/logout` - Выход пользователя

### 2. User (Пользователь)

- `GET /api/profile` - Получение профиля текущего пользователя

### 3. Content (Контент)

- `GET /api/content/blocks` - Список блоков контента с пагинацией и фильтрацией
- `GET /api/content/blocks/{id}` - Получение конкретного блока контента
- `PATCH /api/content/blocks/{blockId}/progress` - Обновление прогресса по блоку
- `GET /api/content/categories` - Иерархический список категорий контента

### 4. Theory (Теория)

- `GET /api/theory/cards` - Список теоретических карточек
- `GET /api/theory/cards/{id}` - Получение конкретной карточки
- `PATCH /api/theory/cards/{cardId}/progress` - Обновление прогресса по карточке
- `GET /api/theory/categories` - Категории теоретических карточек

### 5. WebDAV

- `GET /api/webdav/list` - Список файлов из WebDAV директории
- `GET /api/webdav/file` - Получение содержимого файла с WebDAV

### 6. Admin (Администрирование)

- `POST /api/admin/update-content` - Обновление контента из WebDAV
- `POST /api/admin/import-anki` - Импорт карточек из Anki файла

### 7. General (Общие)

- `GET /` - Базовый endpoint

## Как использовать Swagger UI

### 1. Аутентификация

Большинство endpoints требуют аутентификации. Для начала работы:

1. Откройте раздел **Authentication**
2. Используйте `POST /auth/login` для входа
3. В поле **Request body** введите:
   ```json
   {
     "email": "your-email@example.com",
     "password": "your-password"
   }
   ```
4. Нажмите **Execute**
5. После успешного входа cookie сессии будет автоматически сохранен в браузере

### 2. Тестирование endpoints

#### Получение списка блоков контента:

1. Откройте `GET /api/content/blocks`
2. Настройте параметры фильтрации:
   - `page` - номер страницы (по умолчанию 1)
   - `limit` - количество элементов (по умолчанию 10)
   - `mainCategory` - основная категория (например, "JS")
   - `subCategory` - подкатегория (например, "Array")
   - `q` - поиск по тексту
3. Нажмите **Execute**

#### Обновление прогресса:

1. Откройте `PATCH /api/content/blocks/{blockId}/progress`
2. Введите ID блока в параметр пути
3. В теле запроса выберите действие:
   ```json
   {
     "action": "increment"
   }
   ```
   или
   ```json
   {
     "action": "decrement"
   }
   ```

#### Работа с теоретическими карточками:

1. Используйте `GET /api/theory/cards` для получения списка карточек
2. Фильтруйте по категориям с помощью параметров `category` и `subCategory`
3. Обновляйте прогресс через `PATCH /api/theory/cards/{cardId}/progress`

#### Импорт Anki карточек:

1. Откройте `POST /api/admin/import-anki`
2. В разделе **Request body** выберите файл Anki (.txt в формате TSV)
3. Нажмите **Execute**

### 3. Схемы данных

Swagger UI автоматически показывает структуру всех объектов:

- **ContentBlock** - блок контента с кодом и текстом
- **TheoryCard** - теоретическая карточка вопрос-ответ
- **Pagination** - информация о пагинации
- **Error** - стандартная структура ошибок

### 4. Примеры ответов

Каждый endpoint содержит примеры успешных ответов и ошибок. Swagger UI показывает:

- Структуру JSON ответа
- Описание каждого поля
- Возможные коды ошибок
- Примеры значений

## Особенности работы

### Аутентификация через cookies

API использует сессионную аутентификацию через cookies. После успешного входа через `/auth/login`, все последующие запросы будут автоматически аутентифицированы.

### Пагинация

Endpoints со списками поддерживают пагинацию:

- `page` - номер страницы (начиная с 1)
- `limit` - количество элементов на странице
- Ответ содержит объект `pagination` с информацией о текущей странице и общем количестве элементов

### Фильтрация и поиск

- Фильтрация по категориям: `mainCategory`, `subCategory`
- Полнотекстовый поиск: параметр `q`
- Сортировка: `sortBy` и `sortOrder`

### Обработка файлов

- WebDAV endpoints работают с файлами на удаленном сервере
- Импорт Anki поддерживает загрузку файлов через multipart/form-data
- Автоматическое определение MIME типов для файлов

## Отладка

Если возникают ошибки:

1. Проверьте, что вы аутентифицированы (выполнили `/auth/login`)
2. Убедитесь, что параметры запроса корректны
3. Проверьте консоль браузера на наличие ошибок
4. Используйте примеры из документации Swagger

## Сравнение с Postman

| Функция               | Swagger UI     | Postman         |
| --------------------- | -------------- | --------------- |
| Установка             | Не требуется   | Требуется       |
| Синхронизация с кодом | Автоматическая | Ручная          |
| Документация          | Встроенная     | Отдельная       |
| Примеры               | Автогенерация  | Ручное создание |
| Тестирование          | В браузере     | В приложении    |
| Совместная работа     | Через URL      | Через workspace |

Swagger UI предоставляет более интегрированный опыт разработки, где документация и тестирование API объединены в одном интерфейсе.

## Структура API

### Теги (разделы):

#### **Theory Cards**

- `GET /api/theory/cards` - Список карточек
- `GET /api/theory/cards/{id}` - Конкретная карточка
- `PATCH /api/theory/cards/{cardId}/progress` - Обновление прогресса
- `GET /api/theory/categories` - Категории карточек

#### **Admin**

- `POST /api/admin/update-content` - Обновление контента из WebDAV
- `POST /api/admin/import-anki` - Импорт Anki файла

#### **User**

- `GET /api/profile` - Профиль пользователя

#### **General**

- `GET /` - Базовый endpoint

## Схемы данных

В разделе "Schemas" можно найти описание всех структур данных:

- `TheoryCard` - Структура теоретической карточки
- `TheoryCardsList` - Список карточек с пагинацией
- `TheoryCategory` - Категория карточек
- `ProgressUpdate` - Запрос на обновление прогресса
- `ImportSummary` - Результат импорта
- `User` - Данные пользователя
- `Error` - Структура ошибки

## Советы по использованию

1. **Начните с простых GET запросов** для понимания структуры данных
2. **Используйте примеры** из документации для заполнения полей
3. **Проверяйте Response codes** - 200 означает успех, 4xx - ошибки клиента, 5xx - ошибки сервера
4. **Копируйте curl команды** для использования в скриптах
5. **Изучайте схемы данных** для понимания структуры объектов

## Заключение

Swagger UI предоставляет удобный способ изучения и тестирования API без необходимости установки дополнительных инструментов. Это особенно полезно для:

- Быстрого тестирования новых endpoints
- Изучения структуры API
- Демонстрации возможностей API другим разработчикам
- Отладки проблем с запросами
